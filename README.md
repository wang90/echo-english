# Echo English · 英语口语与阅读练习室

一个零依赖、可直接在浏览器里运行的英语学习网站。
在线体验：[https://wang90.github.io/echo-english/](https://wang90.github.io/echo-english/)
目标很明确：在没有语言环境的情况下，用“阅读输入 + 口语输出 + 生词复习”三件事，持续提升英语能力。

## 功能

### 1. 英文阅读
- 6 篇新闻风格文章，覆盖 A2 / B1 / B2 三个难度
- 支持全文朗读、单句朗读、中英对照、逐段精读
- 点击任意英文单词即可查看音标、词性和中文释义
- 可加入生词本，自动高亮
- 每篇文章附带 3 道理解测验

### 2. 口语对话
- 6 个真实场景：自我介绍、咖啡店点单、问路、同事闲聊、酒店入住、工作面试
- 对方先说，你再用英文回答
- 支持浏览器语音识别；如果麦克风不方便，也可以直接打字
- 系统会按关键词和句型给出匹配反馈，答对后继续下一轮
- 答错的句子会显示参考表达和提示，不会直接“失败”

### 3. 生词复习
- 阅读时一键收藏生词
- 卡片式复习：先回忆，再翻面确认
- 采用简单的间隔重复算法：不熟的词很快再次出现，熟悉的词间隔逐渐拉长
- 记录每个词的熟悉度和下次复习时间

### 4. 学习进度
- 阅读、对话、复习任务自动记录
- 连续学习天数、最近 7 天练习次数、周打卡
- 所有数据保存在当前浏览器的 localStorage 中，不需要注册账号

## 快速开始

在项目目录里运行：

```bash
python3 start.py
```

浏览器会自动打开 `http://localhost:8899`。如果没有自动打开，手动访问这个地址即可。

也可以直接双击 `start.py`，或者用任意静态服务器打开 `index.html`。不过推荐使用 `start.py`，因为语音识别需要 localhost 或 HTTPS 环境。

## 浏览器建议

- 推荐使用最新版 Chrome 或 Edge
- 语音识别会请求麦克风权限，第一次使用时请允许
- 如果浏览器不支持语音识别，网站会自动允许你用键盘输入完成对话
- 发音由浏览器自带的语音合成提供，不同系统可用的英文音色不同
- 如果默认配音听起来奇怪或吓人，进入「设置 → 发音设置」，点击「恢复推荐自然音色」，或手动选择带 Samantha、Ava、Google、Natural、Aria、Jenny 等字样的声音

## 关于在线词典

本地内置了核心词库和文章核心词。遇到词库中没有的词时，如果开启了“允许在线词典补充”，网站会尝试调用：

- `api.mymemory.translated.net`：补充中文翻译
- `api.dictionaryapi.dev`：补充音标和英文例句

如果网络不可用，可以关闭这个选项，网站仍可正常使用内置词库。

## 如何扩展内容

### 添加文章
编辑 `js/data-articles.js`，按照现有结构新增对象即可。每篇文章包含：

- `title`、`source`、`date`、`level`、`topic`、`icon`、`minutes`
- `summary`
- `paragraphs`：英文 `en` 与中文 `zh`
- `vocab`：核心词、音标、词性、释义、例句
- `quiz`：理解题、选项、答案和解析

### 添加口语场景
编辑 `js/data-dialogues.js`，新增一个对话对象。每一轮包含：

- `ai`：对方说的话
- `aiZh`：中文翻译
- `hint`：回答提示
- `sample`：参考表达
- `accept`：可接受的关键词或短语数组

## 数据与隐私

- 学习进度、生词和设置只保存在你的浏览器里
- 没有账号系统，也不会上传个人学习数据
- 语音识别由浏览器的 Web Speech API 完成，具体数据策略取决于浏览器提供方
